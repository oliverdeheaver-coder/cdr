From wrist to web page

Oliver's Xiaomi Watch S1 Active collects steps, sleep and heart rate every day. This project gets that data off the watch, keeps every day of it permanently, and shows it on a private web page.

The data path

Seven hops from the watch to the page

Xiaomi offers no public API or export for this watch, so the data takes the long way round through Android's Health Connect.

WatchPhoneGoogle cloud
  1. Wrist

    Xiaomi Watch S1 Active

    Records the raw daily numbers.

  2. Phone

    Mi Fitness

    Xiaomi's app syncs the watch over Bluetooth, then shares steps, sleep and heart rate into Health Connect.

  3. Phone

    Health Connect

    Android's on-device health store. It has no web API, which is why the next hop exists.

  4. Phone

    Health Sync

    The bridge app. It reads Health Connect and writes CSV files to Google Drive on a schedule.

  5. Cloud

    Google Drive

    CSV files covering rolling windows: today, this week, this month. Older days fall off the end.

  6. Cloud

    Apps Script archive

    Runs every hour, merges the CSVs into a Google Sheet with one row per day, and never deletes anything. This is the part that makes the history last.

  7. Cloud

    Dashboard web app

    The same script serves a private page with charts and 7-day, 30-day, 90-day and all-time views.

How it came together

One afternoon, four steps

Step 1 · Research

No front door

Checked for a Xiaomi API. There isn't one for this watch, and Mi Fitness has no file export.

Step 2 · Route

Daily data wins

Strava would only cover workouts. Daily steps and sleep meant going through Health Connect.

Step 3 · Version 1

Three files

An archive script, an HTML page and a setup guide. It worked, but it needed links, GitHub and manual column numbers.

Step 4 · Version 2

One file

Everything folded into a single Apps Script that finds its own columns and serves its own page. Tested before handover.

The files

What each one does

HealthDashboard.gsUse this one

The all-in-one script. Paste it into a Google Sheet's Apps Script editor and it does the whole job.

  • setup() runs the first import and schedules one every hour
  • syncAll() reads the CSVs and archives each day
  • doGet() serves the dashboard page
  • inspectFiles() logs the CSV columns if anything needs fixing

Under the hood

The clever bits

mergeIntoSheet_

Keeps every day

New days are added and changed days are updated, so today's step count keeps climbing. Rows are never removed, even after Health Sync's files have moved on.

detectDateCol_ · detectValueCol_

Finds its own columns

Looks for the column that's mostly dates, then the numeric column whose header mentions steps, sleep or bpm.

toNumber_

Reads sleep times

Turns durations like 7:30 into 450 minutes, and copes with 72,5 as well as 72.5.

normaliseDate_

Speaks British dates

Reads 09/10/2026 as 9 October, not 10 September, and stores every date as 2026-10-09.

syncAll

Newest file wins

When the day, week and month files overlap, the most recently updated file sets the value for that day.

doGet

Private by default

Deployed as "Only myself", the page needs Oliver's Google sign-in. No public links to the data.

Getting it live

Tonight's checklist

  1. Phone: in Mi Fitness, turn on sharing to Health Connect for steps, sleep and heart rate.
  2. Phone: in Health Sync, set Health Connect as the source and Google Drive CSV as the destination, with automatic sync on.
  3. Sheet: create a Google Sheet, open Extensions → Apps Script, paste HealthDashboard.gs and save.
  4. Run: choose setup and click Run, then approve the permissions.
  5. Deploy: Deploy → New deployment → Web app, as Me, for Only myself. Bookmark the URL on the phone.
Watch out

Xiaomi phones close background apps aggressively. Set Mi Fitness and Health Sync to "No restrictions" for battery and turn on Autostart, or days will go missing. If a chart is empty, run inspectFiles and check the log.
